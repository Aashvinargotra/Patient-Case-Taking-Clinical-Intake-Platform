# MediKiosk — Web Portals (React + Vite + Tailwind CSS)

Consolidated web portal containing role-based interfaces for:
1. **Doctor Interface (`/doctor`):** OPD queue/worklist, Patient ID search, clinical summary review, medical timeline, abnormal lab callouts, and digital summary verification/sign-off.
2. **Admin Portal (`/admin`):** Department queue tracking, OPD analytics, and immutable audit logs.
3. **Patient Portal (`/patient`):** Pre-OPD intake from home, ABHA/MPIN login, longitudinal record viewer, and DPDP data rights management (consent history & data erasure).
