# MediKiosk — Patient Kiosk & Universal Accessibility Client (Flutter)

This module implements the patient-facing clinical intake kiosk interface.

## Core Features
- **50/50 Dual-Mode Home Screen:** Modern Medicine & AYUSH / Ayurveda (Dashavidha Pariksha)
- **Universal Accessibility:** Screen-touch-free conversational voice loop for visually impaired users (TalkBack / WCAG 2.1 AA compliant).
- **Multilingual Support:** Hindi, English, Punjabi, and regional languages.
- **Document Camera Integration:** High-contrast prescription and lab report document capture.
- **Digital & Thermal Print Slip:** Issues privacy-preserving signed QR tokens.
